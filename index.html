市場觀察

高齡比與租金呈負相關

高齡比最高的嘉義縣、南投縣、雲林縣租金僅6,000元左右；租金最高的雙北高齡比反而中等偏上（台北24.18%為例外）。意涵：高齡人口多的地方付不起高端住宅，A/B型高端線只能在雙北與台中都會區；中南部與東部要走大眾線與照護線。

資料分級：A 級

電梯溢價20–30%＝適老改造的定價基礎

官方首度統計證實電梯大樓（6樓以上）租金中位數較公寓（5樓以下）高2至3成（限「整戶(層)」與「獨立套房」兩種型態，分租套雅房未納入統計）。這是『無電梯老公寓換居到電梯宅』價差的官方依據，也是適老化改造能收溢價的證據。

資料分級：A 級

台北市是換居族最大市場

全台高齡比最高（24.18%）＋老公寓密度高＋租金高（12,500）＝原屋出租收益足以支付新居，換居模式的經濟基礎最強。

資料分級：A 級

台中租屋市場規模最大

台中租金中位數僅7,800元，與高雄同為六都次低——若走大眾線（代管＋安心訂閱），成本結構比雙北寬鬆。【待查證】原稿「租補件數8.3萬件全國最多」查無官方出處（內政部115上半年統計之83.3萬件為全國樣本總數，非台中單一縣市），已移除該論據；規模化首選之判斷須待各縣市租補件數官方資料到位後再定。

資料分級：C 級

居住路徑

換居族（有房但不適老）

  1. 原屋健檢與換居試算
  2. 原屋交平台代管出租
  3. 搬入適老宅（A/B型或大眾宅）
  4. 加購安心訂閱
  5. 老化後接照護協調

雙邊租約：同一位長輩同時是房東與房客——房源與客戶一次取得，是本案最獨特的路徑。

獨居／老老家庭

  1. 不搬家（住宅不變）
  2. 裝設感測與緊急通報
  3. 安心訂閱月費
  4. 異常事件應變
  5. 必要時接居服／日照

服務進到既有住宅：不需要房源，靠訂閱滲透存量市場，是規模引擎。

出院銜接／術後

  1. 醫院出院準備小組轉介
  2. 短中期友善住宅入住
  3. 居家照護＋復能
  4. 恢復後轉常規住戶或返家

高週轉路徑（平均在住約4–5個月）：靠集團醫院導流，關鍵在3天內完成入住。

海外／旅外返台

  1. 海外諮詢與安居評估
  2. 返台體驗或試住
  3. 簽約入住 A／B 型
  4. 生活管家＋社群
  5. 照護升級

高齡租屋困難族

  1. 需求登記與資格確認
  2. 房東端風險管理（我們背書）
  3. 媒合入住（代管／包租）
  4. 加購安心訂閱

平台的價值是讓房東敢把房子租給高齡者——解的是市場失靈，不是價格。

活躍退休族（55–70）

  1. 社群接觸／說明會
  2. B型共生住宅入住
  3. 社群年費與活動參與
  4. 未來照護優先權

住得最久、最穩定，五年累計貢獻最大；賣的是社群與未來的安心。

機構客戶 B2B／B2G

  1. 標案或建商洽談
  2. 代營運／顧問合約
  3. 交付與履約評鑑
  4. 續約或SaaS輸出

以示範期實績數據為投標材料；不佔用Cluster營運人力才接。

三、法遵原則

四項不可退讓原則： ①服務資格：身體照顧、關懷訪視、緊急救援等有法定提供者資格之服務，由合格機構提供； ②名稱與廣告：非長照機構不得使用長照名稱或為長照廣告； ③資料分庫：住宅資料與健康照護資料分庫管理，健康資料屬特種個資，蒐集須經當事人明示同意； ④收益揭露：所有財務內容均為管理假設與情境分析，不作收益保證，不使用保證收益話術。
